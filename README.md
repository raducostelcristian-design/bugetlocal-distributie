# Buget și finanțe — distribuție

Repository de distribuție publică pentru aplicația Windows.

Aplicație Windows x64 cu finanțe locale. Site static fără tracking sau backend financiar. Manualul și imaginile conțin numai exemple sintetice.

Installerul se atașează ca asset de GitHub Release, nu se comite în Git. Versiunile anterioare au fost instalate pe calculatorul autorului. Pachetul 1.6.3 a trecut testele automate și se distribuie ca versiune beta nesemnată. Instalarea pe un Windows curat fără WebView2 rămâne de verificat.

Nu încărca data, work, baze SQLite, extrase sau backupuri financiare.
